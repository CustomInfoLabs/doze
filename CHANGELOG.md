# Changelog

## 1.0.0 — Prima release / First release

### Italiano

Prima release di Doze, la utility Windows di CustomInfo per programmare le azioni energetiche del PC.

- Spegnimento, riavvio, sospensione e ibernazione con countdown annullabile.
- Durata impostabile da tastiera, pulsanti + e − e intervalli rapidi.
- Opzione di chiusura forzata per spegnimento e riavvio.
- Blocco del PC e annullamento degli spegnimenti pianificati da Windows.
- Controllo dell’ibernazione e attivazione/disattivazione su richiesta, con autorizzazione di amministratore.
- Interfaccia nativa personalizzata, temi chiaro e scuro, italiano e inglese con scelta automatica iniziale dalla lingua di Windows.
- Preferenze salvate per l’utente corrente e pannello Informazioni con collegamento al sito ufficiale.
- Icona Windows con fondo grafite e angoli tagliati per eseguibile e installer; monogramma trasparente nell’interfaccia.
- Pacchetto portable per provare il programma senza installazione e installer Windows per utente.
- Avvio opzionale tramite Shift + tasto destro su desktop e cartelle, con voce nella parte bassa del menu classico.
- Disinstallazione dei file, dei collegamenti e delle voci del menu create dal setup, con scelta sulla conservazione delle preferenze.
- Guida utente e licenza CustomInfo bilingui incluse nella cartella installata.
- Sorgente completo accompagnato da documentazione di compilazione e test automatizzati.

### English

First release of Doze, the Windows utility by CustomInfo for scheduling PC power actions.

- Shutdown, restart, sleep and hibernation with a cancellable countdown.
- Duration entered using the keyboard, + and − buttons or quick presets.
- Optional forced application closure for shutdown and restart.
- PC locking and cancellation of shutdowns scheduled through Windows.
- Hibernation status checking and enabling/disabling on request, with administrator approval.
- Custom native interface, light and dark themes, Italian and English with the initial language chosen from Windows settings.
- Preferences saved for the current user and an About panel linking to the official website.
- Windows icon with a graphite background and cut corners for the executable and installer; transparent monogram inside the interface.
- Portable package for testing without installation and a per-user Windows installer.
- Optional Shift + right-click access on the desktop and folders, with an entry near the bottom of the classic context menu.
- Uninstallation removes the files, shortcuts and menu entries created by setup, with a choice about retaining preferences.
- Bilingual user guide and CustomInfo licence included in the installed folder.
- Complete source code accompanied by build documentation and automated tests.
